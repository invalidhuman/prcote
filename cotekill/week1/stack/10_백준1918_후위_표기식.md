# 백준1918 후위 표기식

- 난이도: 어려움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/1918)

## 문제 요약

대문자 피연산자, 사칙연산자, 괄호로 된 중위 표기식을 괄호 없는 후위 표기식으로 변환한다.

## solution 인터페이스

```js
function solution(expression) {
    // ...
}
```

- `expression`: solution에 전달할 입력
- 반환값: `string`

## 제한 및 주의사항

- 피연산자는 A-Z 한 글자
- 연산 우선순위와 괄호를 지켜야 한다.
- 식 길이는 100 이하

## 공개 예제

- 예제 1: `["A+B*C"]` → `"ABC*+"`
- 예제 2: `["A*(B+C)"]` → `"ABC+*"`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
