# 백준1935 후위 표기식2

- 난이도: 보통
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/1935)

## 문제 요약

대문자 피연산자와 사칙연산자로 된 후위 표기식을 계산한다. values[0]은 A, values[1]은 B에 대응한다.

## solution 인터페이스

```js
function solution(expression, values) {
    // ...
}
```

- `expression`: solution에 전달할 입력
- `values`: solution에 전달할 입력
- 반환값: `number`

## 제한 및 주의사항

- 피연산자 수는 1 이상 26 이하
- 식에 등장하는 각 피연산자는 한 글자 대문자
- 나눗셈은 실수 연산으로 처리

## 공개 예제

- 예제 1: `["ABC*+DE/-",[1,2,3,4,5]]` → `6.2`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
