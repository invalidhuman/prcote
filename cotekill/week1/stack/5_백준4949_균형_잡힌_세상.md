# 백준4949 균형 잡힌 세상

- 난이도: 쉬움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/4949)

## 문제 요약

각 문장에서 소괄호와 대괄호가 종류와 중첩 순서까지 올바르게 짝지어졌는지 yes 또는 no로 반환한다.

## solution 인터페이스

```js
function solution(lines) {
    // ...
}
```

- `lines`: solution에 전달할 입력
- 반환값: `string[]`

## 제한 및 주의사항

- 각 문장 길이는 100 이하
- 괄호 이외 문자는 판정에서 무시
- 원문의 종료 표식 '.'은 파라미터에 포함하지 않는다.

- 예제 1: `[["So when I die (the [first] I will see in (heaven) is a score list).","[ first in ] ( first out ).","Half Moon tonight (At least it is better than no Moon at all].","A rope may form )( a trail in a maze.","Help( I[m being held prisoner in a fortune cookie factory)].","([ (([( [ ] ) ( ) (( ))] )) ])."," ."]]` → `["yes","yes","no","no","no","yes","yes"]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
