# 프로그래머스42584 주식가격

- 난이도: 보통 · Level 2
- 분류: Stack
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/42584)

## 문제 요약

초 단위 주가 배열에서 각 시점의 가격이 떨어지지 않은 기간을 초 단위로 반환한다.

## solution 인터페이스

```js
function solution(prices) {
    // ...
}
```

- `prices`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- prices 길이는 2 이상 100,000 이하
- 각 가격은 1 이상 10,000 이하

## 공개 예제

- 예제 1: `[[1,2,3,2,3]]` → `[4,3,1,1,0]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
