# 백준17298 오큰수

- 난이도: 어려움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/17298)

## 문제 요약

각 원소의 오른쪽에서 처음 만나는 더 큰 수를 반환한다. 존재하지 않으면 -1을 반환한다.

## solution 인터페이스

```js
function solution(numbers) {
    // ...
}
```

- `numbers`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 수열 길이는 최대 1,000,000
- 원소는 1 이상 1,000,000 이하

## 공개 예제

- 예제 1: `[[3,5,2,7]]` → `[5,7,7,-1]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
