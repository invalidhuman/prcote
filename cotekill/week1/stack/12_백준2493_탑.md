# 백준2493 탑

- 난이도: 어려움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/2493)

## 문제 요약

각 탑이 왼쪽으로 보낸 레이저를 처음 수신하는 탑의 1 기반 번호를 반환한다. 없으면 0을 반환한다.

## solution 인터페이스

```js
function solution(heights) {
    // ...
}
```

- `heights`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 탑 수는 최대 500,000
- 모든 탑 높이는 서로 다르다.

## 공개 예제

- 예제 1: `[[6,9,5,7,4]]` → `[0,0,2,2,4]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
