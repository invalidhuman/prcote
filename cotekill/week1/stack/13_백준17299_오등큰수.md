# 백준17299 오등큰수

- 난이도: 매우 어려움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/17299)

## 문제 요약

각 원소의 오른쪽에서 처음 만나는, 전체 수열 등장 횟수가 현재 원소보다 많은 수를 반환한다. 없으면 -1을 반환한다.

## solution 인터페이스

```js
function solution(numbers) {
    // ...
}
```

- `numbers`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 수열 길이는 최대 1,000,000
- 원소는 1 이상 1,000,000 이하

## 공개 예제

- 예제 1: `[[1,1,2,3,4,2,1]]` → `[-1,-1,1,2,2,1,-1]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
