# 백준10773 제로

- 난이도: 쉬움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/10773)

## 문제 요약

숫자를 차례대로 기록하되 0이 나오면 가장 최근 숫자를 지운다. 마지막에 남은 숫자의 합을 반환한다.

## solution 인터페이스

```js
function solution(numbers) {
    // ...
}
```

- `numbers`: solution에 전달할 입력
- 반환값: `number`

## 제한 및 주의사항

- 숫자 개수 K는 최대 100,000
- 0이 나올 때 지울 숫자가 항상 존재한다.
- 각 숫자는 0 이상 1,000,000 이하

## 공개 예제

- 예제 1: `[[3,0,4,0]]` → `0`
- 예제 2: `[[1,3,5,4,0,0,7,0,0,6]]` → `7`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
