# 백준10828 스택

- 난이도: 입문
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/10828)

## 문제 요약

정수를 저장하는 스택을 만들고 명령을 처리한다. 값을 출력하는 명령의 결과만 순서대로 반환한다.

## solution 인터페이스

```js
function solution(commands) {
    // ...
}
```

- `commands`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 명령 수 N은 최대 10,000
- push X, pop, size, empty, top을 처리한다.
- 빈 스택의 pop/top 결과는 -1

## 공개 예제

- 예제 1: `[["push 1","push 2","top","size","empty","pop","pop","pop","size","empty","pop","push 3","empty","top"]]` → `[2,2,0,2,1,-1,0,1,-1,0,3]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
