# 백준1874 스택 수열

- 난이도: 보통
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/1874)

## 문제 요약

1부터 n까지 수를 차례로 한 번씩 push하고 필요할 때 pop해 목표 수열을 만든다. 가능한 연산(+/-) 목록을 반환하고 불가능하면 null을 반환한다.

## solution 인터페이스

```js
function solution(target) {
    // ...
}
```

- `target`: solution에 전달할 입력
- 반환값: `string[] | null`

## 제한 및 주의사항

- target은 1..n의 순열
- n은 최대 100,000

## 공개 예제

- 예제 1: `[[4,3,6,8,7,5,2,1]]` → `["+","+","+","+","-","-","+","+","-","+","+","-","-","-","-","-"]`
- 예제 2: `[[1,2,5,3,4]]` → `null`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
