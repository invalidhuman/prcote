# 프로그래머스12909 올바른 괄호

- 난이도: 쉬움 · Level 2
- 분류: Stack
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/12909)

## 문제 요약

'('와 ')'로 이루어진 문자열이 올바르게 짝지어졌는지 반환한다.

## solution 인터페이스

```js
function solution(s) {
    // ...
}
```

- `s`: solution에 전달할 입력
- 반환값: `boolean`

## 제한 및 주의사항

- 문자열 길이는 1 이상 100,000 이하
- 문자열은 '('와 ')'만 포함

## 공개 예제

- 예제 1: `["()()"]` → `true`
- 예제 2: `["(())()"]` → `true`
- 예제 3: `[")()("]` → `false`
- 예제 4: `["(()("]` → `false`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
