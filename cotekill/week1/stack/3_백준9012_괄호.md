# 백준9012 괄호

- 난이도: 쉬움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/9012)

## 문제 요약

각 괄호 문자열이 올바르게 짝지어졌는지 판별해 YES 또는 NO를 반환한다.

## solution 인터페이스

```js
function solution(strings) {
    // ...
}
```

- `strings`: solution에 전달할 입력
- 반환값: `string[]`

## 제한 및 주의사항

- 문자열은 '('와 ')'로만 구성
- 각 문자열 길이는 2 이상 50 이하

## 공개 예제

- 예제 1: `[["(())())","(((()())()","(()())((()))","((()()(()))(((())))()","()()()()(()()())()","(()((())()("]]` → `["NO","NO","YES","NO","YES","NO"]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
