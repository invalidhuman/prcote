# 백준3015 오아시스 재결합

- 난이도: 매우 어려움
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/3015)

## 문제 요약

일렬로 선 사람 중 서로 볼 수 있는 쌍의 수를 반환한다. 두 사람 사이에 둘보다 키 큰 사람이 없을 때 서로 볼 수 있다.

## solution 인터페이스

```js
function solution(heights) {
    // ...
}
```

- `heights`: solution에 전달할 입력
- 반환값: `number`

## 제한 및 주의사항

- 사람 수는 최대 500,000
- 키는 1 이상 2^31 미만
- 정답이 32비트 정수 범위를 넘을 수 있다.

## 공개 예제

- 예제 1: `[[2,4,1,2,2,5,1]]` → `10`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
