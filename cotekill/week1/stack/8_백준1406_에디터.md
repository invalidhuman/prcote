# 백준1406 에디터

- 난이도: 보통
- 분류: Stack
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/1406)

## 문제 요약

문자열 사이를 이동하는 커서에 대해 왼쪽 이동, 오른쪽 이동, 왼쪽 문자 삭제, 문자 삽입 명령을 수행한 최종 문자열을 반환한다.

## solution 인터페이스

```js
function solution(initialText, commands) {
    // ...
}
```

- `initialText`: solution에 전달할 입력
- `commands`: solution에 전달할 입력
- 반환값: `string`

## 제한 및 주의사항

- 초기 문자열은 소문자이며 길이는 최대 100,000
- 명령 수는 최대 500,000
- L, D, B, P x 명령을 처리한다.

## 공개 예제

- 예제 1: `["abc",["P x","L","P y"]]` → `"abcyx"`
- 예제 2: `["abc",["L","L","L","L","L","P x","L","B","P y"]]` → `"yxabc"`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
