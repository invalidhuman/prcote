# 백준1966 프린터 큐

- 난이도: 보통
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/1966)

## 문제 요약

각 테스트 케이스에서 중요도가 더 높은 문서가 큐에 남아 있으면 현재 문서를 뒤로 보낸다. 지정 문서가 몇 번째로 인쇄되는지 반환한다.

## solution 인터페이스

```js
function solution(testCases) {
    // ...
}
```

- `testCases`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- testCases의 각 원소는 { priorities, location } 형태
- 문서 수는 1 이상 100 이하
- 중요도는 1 이상 9 이하

## 공개 예제

- 예제 1: `[[{"priorities":[1],"location":0},{"priorities":[1,2,3,4],"location":2},{"priorities":[1,1,9,1,1,1],"location":0}]]` → `[1,2,5]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
