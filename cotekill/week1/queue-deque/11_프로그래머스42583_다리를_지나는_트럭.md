# 프로그래머스42583 다리를 지나는 트럭

- 난이도: 보통 · Level 2
- 분류: Queue / Deque
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/42583)

## 문제 요약

트럭이 순서대로 일차선 다리를 건넌다. 다리 길이와 허용 무게를 넘지 않으며 모든 트럭이 건너는 최소 시간을 반환한다.

## solution 인터페이스

```js
function solution(bridgeLength, weight, truckWeights) {
    // ...
}
```

- `bridgeLength`: solution에 전달할 입력
- `weight`: solution에 전달할 입력
- `truckWeights`: solution에 전달할 입력
- 반환값: `number`

## 제한 및 주의사항

- bridgeLength와 weight는 1 이상 10,000 이하
- 트럭 수는 1 이상 10,000 이하
- 각 트럭 무게는 1 이상 weight 이하

## 공개 예제

- 예제 1: `[2,10,[7,4,5,6]]` → `8`
- 예제 2: `[100,100,[10]]` → `101`
- 예제 3: `[100,100,[10,10,10,10,10,10,10,10,10,10]]` → `110`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
