# 백준5430 AC

- 난이도: 어려움
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/5430)

## 문제 요약

각 테스트 케이스에서 R은 배열 방향을 뒤집고 D는 현재 앞 원소를 버린다. 결과 배열 문자열 또는 error를 반환한다.

## solution 인터페이스

```js
function solution(testCases) {
    // ...
}
```

- `testCases`: solution에 전달할 입력
- 반환값: `string[]`

## 제한 및 주의사항

- 각 원소는 { commands, array } 형태
- 빈 배열에 D를 적용하면 error
- 명령 길이 합과 배열 길이 합이 크므로 실제 reverse를 반복하지 않는다.

## 공개 예제

- 예제 1: `[[{"commands":"RDD","array":[1,2,3,4]},{"commands":"DD","array":[1,2]},{"commands":"RRD","array":[1,1,2,3,5,8]},{"commands":"D","array":[]}]]` → `["[2,1]","[]","[1,2,3,5,8]","error"]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
