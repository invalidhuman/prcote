# 프로그래머스42587 프로세스

- 난이도: 보통 · Level 2
- 분류: Queue / Deque
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/42587)

## 문제 요약

대기 큐에서 하나를 꺼냈을 때 더 높은 우선순위가 남아 있으면 다시 넣고, 아니면 실행한다. location의 프로세스가 몇 번째로 실행되는지 반환한다.

## solution 인터페이스

```js
function solution(priorities, location) {
    // ...
}
```

- `priorities`: solution에 전달할 입력
- `location`: solution에 전달할 입력
- 반환값: `number`

## 제한 및 주의사항

- 프로세스 수는 1 이상 100 이하
- 우선순위는 1 이상 9 이하
- location은 유효한 0 기반 인덱스

## 공개 예제

- 예제 1: `[[2,1,3,2],2]` → `1`
- 예제 2: `[[1,1,9,1,1,1],0]` → `5`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
