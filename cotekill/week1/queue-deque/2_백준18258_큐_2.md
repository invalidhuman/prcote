# 백준18258 큐 2

- 난이도: 입문
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/18258)

## 문제 요약

대량의 명령을 처리하는 정수 큐를 구현한다. 값을 출력하는 명령의 결과만 순서대로 반환한다.

## solution 인터페이스

```js
function solution(commands) {
    // ...
}
```

- `commands`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 명령 수 N은 최대 2,000,000
- push X의 X는 1 이상 100,000 이하
- 각 연산을 효율적으로 처리해야 한다.

## 공개 예제

- 예제 1: `[["push 1","push 2","front","back","size","empty","pop","pop","pop","size","empty","pop","push 3","empty","front"]]` → `[1,2,2,0,1,2,-1,0,1,-1,0,3]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
