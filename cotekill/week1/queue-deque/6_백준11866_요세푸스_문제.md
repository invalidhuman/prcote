# 백준11866 요세푸스 문제

- 난이도: 쉬움
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/11866)

## 문제 요약

1번부터 N번까지 원을 이루어 앉아 있을 때, 남은 사람 중 K번째 사람을 계속 제거한다. 제거되는 순서를 반환한다.

## solution 인터페이스

```js
function solution(n, k) {
    // ...
}
```

- `n`: solution에 전달할 입력
- `k`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 1 ≤ K ≤ N ≤ 1,000

## 공개 예제

- 예제 1: `[7,3]` → `[3,6,2,7,5,1,4]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
