# 백준10866 덱

- 난이도: 쉬움
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/10866)

## 문제 요약

정수를 저장하는 덱을 만들고 양 끝 삽입·삭제·조회 명령을 처리한다. 값을 출력하는 명령의 결과만 반환한다.

## solution 인터페이스

```js
function solution(commands) {
    // ...
}
```

- `commands`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 명령 수 N은 최대 10,000
- push_front X, push_back X, pop_front, pop_back, size, empty, front, back을 처리한다.

## 공개 예제

- 예제 1: `[["push_back 1","push_front 2","front","back","size","empty","pop_front","pop_back","pop_front","size","empty","pop_back","push_front 3","empty","front"]]` → `[2,1,2,0,2,1,-1,0,1,-1,0,3]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
