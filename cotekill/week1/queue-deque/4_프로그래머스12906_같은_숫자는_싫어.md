# 프로그래머스12906 같은 숫자는 싫어

- 난이도: 쉬움 · Level 1
- 분류: Queue / Deque
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/12906)

## 문제 요약

배열에서 연속으로 같은 숫자가 나타나면 하나만 남긴다. 원래 순서를 유지한 결과를 반환한다.

## solution 인터페이스

```js
function solution(arr) {
    // ...
}
```

- `arr`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- arr 길이는 1 이상 1,000,000 이하
- 원소는 0 이상 9 이하

## 공개 예제

- 예제 1: `[[1,1,3,3,0,1,1]]` → `[1,3,0,1]`
- 예제 2: `[[4,4,4,3,3]]` → `[4,3]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
