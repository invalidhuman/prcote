# 백준1021 회전하는 큐

- 난이도: 보통
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/1021)

## 문제 요약

1부터 N까지 든 양방향 큐에서 목표 원소들을 순서대로 꺼낸다. 왼쪽 또는 오른쪽 회전 연산의 최소 횟수를 반환한다.

## solution 인터페이스

```js
function solution(n, targets) {
    // ...
}
```

- `n`: solution에 전달할 입력
- `targets`: solution에 전달할 입력
- 반환값: `number`

## 제한 및 주의사항

- 첫 원소 제거 자체는 회전 횟수에 포함하지 않는다.
- targets의 원소는 서로 다르다.
- N은 50 이하

## 공개 예제

- 예제 1: `[10,[1,2,3]]` → `0`
- 예제 2: `[10,[2,9,5]]` → `8`
- 예제 3: `[32,[27,16,30,11,6,23]]` → `59`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
