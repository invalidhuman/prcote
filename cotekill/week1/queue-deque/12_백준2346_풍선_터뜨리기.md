# 백준2346 풍선 터뜨리기

- 난이도: 보통
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/2346)

## 문제 요약

1번 풍선부터 터뜨리고, 안의 이동값만큼 원형으로 이동해 다음 풍선을 터뜨린다. 터지는 풍선 번호 순서를 반환한다.

## solution 인터페이스

```js
function solution(moves) {
    // ...
}
```

- `moves`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 풍선 수는 1 이상 1,000 이하
- 이동값은 0이 아니며 절댓값이 풍선 수 이하
- 양수는 오른쪽, 음수는 왼쪽으로 이동한다.

## 공개 예제

- 예제 1: `[[3,2,1,-3,-1]]` → `[1,4,5,3,2]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
