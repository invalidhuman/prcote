# 백준11003 최솟값 찾기

- 난이도: 어려움
- 분류: Queue / Deque
- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/11003)

## 문제 요약

각 인덱스 i에서 numbers[max(0, i-windowSize+1)..i]의 최솟값을 구해 순서대로 반환한다.

## solution 인터페이스

```js
function solution(numbers, windowSize) {
    // ...
}
```

- `numbers`: solution에 전달할 입력
- `windowSize`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- N은 최대 5,000,000
- 1 ≤ windowSize ≤ N
- 선형 시간에 가까운 풀이가 필요하다.

## 공개 예제

- 예제 1: `[[1,5,2,3,6,2,3,7,3,5,2,6],3]` → `[1,1,1,2,2,2,2,2,3,3,2,2]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
