# 프로그래머스42586 기능개발

- 난이도: 보통 · Level 2
- 분류: Queue / Deque
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/42586)

## 문제 요약

각 기능의 진도와 일일 개발 속도가 주어진다. 앞 기능이 배포될 때 완성된 뒤 기능도 함께 배포하며, 배포마다 기능 수를 반환한다.

## solution 인터페이스

```js
function solution(progresses, speeds) {
    // ...
}
```

- `progresses`: solution에 전달할 입력
- `speeds`: solution에 전달할 입력
- 반환값: `number[]`

## 제한 및 주의사항

- 작업 수는 100 이하
- 진도는 100 미만의 자연수
- 속도는 100 이하의 자연수
- 배포는 하루 끝에 한 번 이루어진다.

## 공개 예제

- 예제 1: `[[93,30,55],[1,30,5]]` → `[2,1]`
- 예제 2: `[[95,90,99,99,80,99],[1,1,1,1,1,1]]` → `[1,3,2]`

> 백준 원문의 표준 입출력을 프로그래머스식 함수 호출과 반환값으로 바꾼 버전입니다.
