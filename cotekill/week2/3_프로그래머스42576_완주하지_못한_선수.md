# 프로그래머스42576 완주하지 못한 선수

- 난이도: Level 1
- 분류: 해시
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/42576?language=javascript)

## 문제 요약

마라톤 참가자 중 완주하지 못한 한 명의 이름을 반환한다. 참가자 중에는 동명이인이 있을 수 있다.

## solution 인터페이스

```js
function solution(participant, completion) {
  // ...
}
```

- `participant`: 참가자의 이름이 담긴 배열
- `completion`: 완주자의 이름이 담긴 배열
- 반환값: 완주하지 못한 선수의 이름

## 제한 및 주의사항

- 참가자는 1명 이상 100,000명 이하이다.
- `completion`의 길이는 `participant`보다 1 작다.
- 이름은 길이 1 이상 20 이하인 알파벳 소문자로 이루어진다.
- 참가자 중에는 동명이인이 있을 수 있다.

## 공개 예제

- 예제 1: `["leo", "kiki", "eden"], ["eden", "kiki"]` → `"leo"`
- 예제 2: `["marina", "josipa", "nikola", "vinko", "filipa"], ["josipa", "filipa", "marina", "nikola"]` → `"vinko"`
- 예제 3: `["mislav", "stanko", "mislav", "ana"], ["stanko", "ana", "mislav"]` → `"mislav"`

## 로컬 테스트

두 실행 명령은 Object를 사용한 첫 번째 풀이와 Map을 사용한 두 번째 풀이를 모두 검사한다.
