# 프로그래머스12946 하노이의 탑

- 난이도: Level 2
- 분류: 재귀
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/12946)

## 문제 요약

1번 기둥에 쌓인 `n`개의 원판을 규칙에 따라 3번 기둥으로 최소 횟수로 옮기는 방법을 반환한다.

- 한 번에 하나의 원판만 옮길 수 있다.
- 큰 원판은 작은 원판 위에 놓을 수 없다.

## solution 인터페이스

```js
function solution(n) {
  var answer = [[]];
  return answer;
}
```

- `n`: 1번 기둥에 있는 원판의 개수
- 반환값: 원판을 옮길 때마다 `[출발 기둥, 도착 기둥]`을 기록한 2차원 배열

## 제한 및 주의사항

- `n`은 15 이하의 자연수이다.
- 원판을 옮기는 횟수는 최소여야 한다.

## 공개 예제

- 예제 1: `2` → `[[1, 2], [1, 3], [2, 3]]`

## 풀이 힌트

`n - 1`개의 원판을 보조 기둥으로 옮기고, 가장 큰 원판을 목표 기둥으로 옮긴 뒤, 보조 기둥의 `n - 1`개 원판을 목표 기둥으로 옮기는 과정을 생각해 본다.
