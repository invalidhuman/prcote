# 3052번 - 나머지

- 원문: [백준 문제 페이지](https://www.acmicpc.net/problem/3052)

## 문제

두 자연수 A와 B가 있을 때, A를 B로 나눈 나머지를 `A % B`라고 표현한다.

수 10개를 입력받은 뒤, 각 수를 42로 나눈 나머지를 구한다. 그 다음 서로 다른 나머지가 몇 개인지 출력한다.

## 입력

첫째 줄부터 열 번째 줄까지 숫자가 한 줄에 하나씩 주어진다. 입력되는 숫자는 0보다 크거나 같고 1,000보다 작거나 같은 정수이다.

## 출력

입력된 10개의 숫자를 각각 42로 나누었을 때 서로 다른 나머지가 몇 개인지 출력한다.

## 풀이 아이디어

### Set 사용

각 숫자를 42로 나눈 나머지를 `Set`에 넣으면 중복이 자동으로 제거된다. 모든 숫자를 처리한 뒤 `Set`의 크기가 정답이다.

### 나머지를 인덱스로 사용

나머지는 항상 0부터 41 사이이므로 길이가 42인 배열을 만들 수 있다. 각 나머지에 해당하는 인덱스를 표시한 뒤 표시된 칸의 개수를 세면 된다.
