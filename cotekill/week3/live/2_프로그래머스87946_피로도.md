# 프로그래머스87946 피로도

- 난이도: Level 2 (중)
- 분류: 완전 탐색, 백트래킹
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/87946?language=javascript)

## 문제 요약

현재 피로도 `k`와 각 던전의 `[최소 필요 피로도, 소모 피로도]`가 주어진다. 하루에 각 던전을 한 번씩만 탐험할 수 있을 때, 탐험 순서를 적절히 정해 방문할 수 있는 최대 던전 수를 반환한다.

## solution 인터페이스

```js
function solution(k, dungeons) {
  // ...
}
```

- `k`: 유저의 현재 피로도
- `dungeons`: 각 던전의 최소 필요 피로도와 소모 피로도 목록
- 반환값: 탐험할 수 있는 최대 던전 수

## 제한 및 주의사항

- `k`는 1 이상 5,000 이하이다.
- 던전 수는 1 이상 8 이하이다.
- 각 던전 정보는 `[최소 필요 피로도, 소모 피로도]`이며 두 값은 1 이상 1,000 이하이다.
- 최소 필요 피로도는 소모 피로도보다 크거나 같다.
- 서로 다른 던전의 정보가 같을 수 있다.
- 현재 피로도가 최소 필요 피로도 이상일 때만 해당 던전에 입장할 수 있다.
- 같은 던전을 두 번 방문하지 않도록 탐색 상태를 복원해야 한다.

## 공개 예제

- `80`, `[[80, 20], [50, 40], [30, 10]]` → `3`
