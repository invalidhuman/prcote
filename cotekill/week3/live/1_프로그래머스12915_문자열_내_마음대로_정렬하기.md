# 프로그래머스12915 문자열 내 마음대로 정렬하기

- 난이도: Level 1 (하)
- 분류: 문자열, 정렬
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/12915?language=javascript)

## 문제 요약

문자열 배열 `strings`를 각 문자열의 인덱스 `n`에 있는 문자를 기준으로 오름차순 정렬한다. 기준 문자가 같다면 문자열 전체의 사전순으로 정렬해 반환한다.

## solution 인터페이스

```js
function solution(strings, n) {
  // ...
}
```

- `strings`: 소문자 알파벳 문자열로 구성된 배열
- `n`: 정렬 기준으로 사용할 문자 인덱스
- 반환값: 지정된 기준에 따라 정렬한 문자열 배열

## 제한 및 주의사항

- `strings`의 길이는 1 이상 50 이하이다.
- 각 문자열의 길이는 1 이상 100 이하이며 소문자 알파벳으로만 이루어진다.
- 모든 문자열의 길이는 `n`보다 크다.
- 인덱스 `n`의 문자가 같으면 문자열 전체를 사전순으로 비교한다.
- `sort()`는 입력 배열 자체를 변경한다.

## 공개 예제

- `["sun", "bed", "car"]`, `1` → `["car", "bed", "sun"]`
- `["abce", "abcd", "cdx"]`, `2` → `["abcd", "abce", "cdx"]`
