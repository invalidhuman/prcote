# 프로그래머스169199 리코쳇 로봇

- 난이도: Level 2 (상)
- 분류: 그래프 탐색, 너비 우선 탐색
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/169199?language=javascript)

## 문제 요약

문자열 배열로 주어진 게임판에서 로봇 `R`을 상하좌우로 움직여 목표 `G`에 정확히 멈추는 최소 이동 횟수를 구한다. 로봇은 한 방향으로 움직이기 시작하면 장애물 `D`나 게임판 가장자리에 부딪히기 직전까지 미끄러지며, 도달할 수 없으면 `-1`을 반환한다.

## solution 인터페이스

```js
function solution(board) {
  // ...
}
```

- `board`: 빈칸 `.`, 장애물 `D`, 시작점 `R`, 목표점 `G`로 이루어진 문자열 배열
- 반환값: 목표점에 도달하는 최소 이동 횟수 또는 도달할 수 없을 때 `-1`

## 제한 및 주의사항

- 행과 열의 길이는 각각 3 이상 100 이하이다.
- 모든 행의 길이는 같다.
- `R`과 `G`는 게임판에 각각 한 번만 등장한다.
- 목표 칸을 지나가기만 해서는 도달한 것이 아니며, 목표 칸에 정확히 멈춰야 한다.
- 한 방향으로 미끄러지는 전체 과정이 한 번의 이동이다.
- 최소 이동 횟수는 각 정지 위치를 정점으로 보는 너비 우선 탐색으로 구할 수 있다.

## 공개 예제

- `["...D..R", ".D.G...", "....D.D", "D....D.", "..D...."]` → `7`
- `[".D.R", "....", ".G..", "...D"]` → `-1`
