# 리트코드104 이진 트리의 최대 깊이

- 난이도: Easy
- 분류: 트리, 깊이 우선 탐색, 너비 우선 탐색, 이진 트리
- 원문: [LeetCode 문제 페이지](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

## 문제 요약

이진 트리의 루트 `root`가 주어질 때 트리의 최대 깊이를 반환한다. 최대 깊이는 루트 노드에서 가장 멀리 있는 리프 노드까지의 경로에 포함된 노드 수이다.

## solution 인터페이스

```js
function solution(root) {
  // ...
}
```

- `root`: 이진 트리의 루트 노드 또는 빈 트리를 나타내는 `null`
- 각 노드는 `val`, `left`, `right` 속성을 갖는다.
- 반환값: 이진 트리의 최대 깊이

LeetCode 제출 시에는 `solution` 함수의 이름을 문제에서 요구하는 `maxDepth`로 바꾼다.

## 제한 및 주의사항

- 노드 수는 0개 이상 10,000개 이하이다.
- 각 노드의 값은 -100 이상 100 이하이다.
- 빈 트리의 최대 깊이는 0이다.
- 자식이 없는 노드 하나로 이루어진 트리의 최대 깊이는 1이다.
- 한쪽으로만 이어진 트리도 입력될 수 있다.

## 공개 예제

- `[3, 9, 20, null, null, 15, 7]` → `3`
- `[1, null, 2]` → `2`

배열은 LeetCode에서 사용하는 레벨 순회 방식의 트리 표현이며, 로컬 테스트가 이 배열을 트리 노드로 변환해 `solution`에 전달한다.
