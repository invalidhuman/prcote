# 프로그래머스43165 타겟 넘버

- 난이도: Level 2
- 분류: 깊이 우선 탐색, 너비 우선 탐색
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/43165?language=javascript)

## 문제 요약

음이 아닌 정수가 담긴 배열 `numbers`의 순서를 바꾸지 않고 각 숫자 앞에 더하기 또는 빼기를 붙인다. 모든 숫자를 사용한 결과가 `target`이 되는 방법의 수를 반환한다.

## solution 인터페이스

```js
function solution(numbers, target) {
  // ...
}
```

- `numbers`: 사용할 자연수가 담긴 배열
- `target`: 만들려는 자연수
- 반환값: 모든 숫자에 더하기 또는 빼기를 적용해 `target`을 만드는 방법의 수

## 제한 및 주의사항

- `numbers`의 길이는 2 이상 20 이하이다.
- `numbers`의 각 원소는 1 이상 50 이하이다.
- `target`은 1 이상 1,000 이하이다.
- 같은 계산 결과가 나오더라도 더하기와 빼기를 선택한 위치가 다르면 서로 다른 방법이다.
- 모든 숫자를 순서대로 한 번씩 사용해야 한다.

## 공개 예제

- `[1, 1, 1, 1, 1]`, `3` → `5`
- `[4, 1, 2, 1]`, `4` → `2`
