# 프로그래머스42748 K번째수

- 난이도: Level 1
- 분류: 정렬
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/42748?language=javascript)

## 문제 요약

숫자 배열과 여러 개의 `[i, j, k]` 명령이 주어진다. 각 명령마다 배열의 i번째부터 j번째까지를 자르고 오름차순으로 정렬한 뒤, k번째 숫자를 결과 배열에 담아 반환한다.

## solution 인터페이스

```js
function solution(array, commands) {
  // ...
}
```

- `array`: 길이 1 이상 100 이하인 숫자 배열
- `commands`: `[i, j, k]`를 원소로 갖는 길이 1 이상 50 이하의 배열
- 반환값: 각 명령을 수행해 얻은 k번째 숫자의 배열

## 제한 및 주의사항

- `array`의 각 원소는 1 이상 100 이하이다.
- 문제의 위치는 1부터 시작하지만 JavaScript 배열 인덱스는 0부터 시작한다.
- `slice(start, end)`의 `end`는 결과에 포함되지 않는다.
- `sort()`는 기본적으로 값을 문자열로 변환해 비교한다. 숫자 오름차순은 `sort((a, b) => a - b)`를 사용해야 한다.
- `sort()`는 배열을 직접 변경하지만, `slice()`로 만든 배열을 정렬하면 원본 `array`는 유지된다.

## 공개 예제

- `[1, 5, 2, 6, 3, 7, 4]`, `[[2, 5, 3], [4, 4, 1], [1, 7, 3]]` → `[5, 6, 3]`
