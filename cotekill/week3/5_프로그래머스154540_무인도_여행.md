# 프로그래머스154540 무인도 여행

- 난이도: Level 2
- 분류: 너비 우선 탐색, 깊이 우선 탐색
- 원문: [프로그래머스 문제 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/154540?language=javascript)

## 문제 요약

문자열 배열 `maps`는 직사각형 격자 지도를 나타낸다. `X`는 바다이고, `1`부터 `9`까지의 숫자는 해당 땅에 있는 식량이다. 상하좌우로 연결된 땅을 하나의 무인도로 보고, 각 무인도에 있는 식량의 합을 오름차순 배열로 반환한다. 무인도가 없으면 `[-1]`을 반환한다.

## solution 인터페이스

```js
function solution(maps) {
  // ...
}
```

- `maps`: 바다와 식량이 표시된 직사각형 지도를 나타내는 문자열 배열
- 반환값: 각 무인도의 식량 합을 오름차순으로 정렬한 배열. 무인도가 없으면 `[-1]`

## 제한 및 주의사항

- `maps`의 길이는 3 이상 100 이하이다.
- `maps[i]`의 길이는 3 이상 100 이하이다.
- `maps[i]`는 `X` 또는 `1`부터 `9`까지의 숫자로 이루어진 문자열이다.
- 지도는 직사각형이다.
- 대각선으로만 맞닿은 땅은 서로 다른 무인도이다.
- 각 무인도의 식량 합을 구한 뒤 오름차순으로 정렬해야 한다.

## 공개 예제

- `["X591X", "X1X5X", "X231X", "1XXX1"]` → `[1, 1, 27]`
- `["XXX", "XXX", "XXX"]` → `[-1]`
